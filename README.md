# ultimate-cookbook
A big, organized collection of recipes in plain Markdown: one file per recipe, grouped into category folders, each with ingredients and step-by-step instructions.

Last updated: 2026-10-08
Recipes: 1008
Categories: 42 folders

What is in this repo
– Cookbook.zip: every recipe, one Markdown file each, sorted into the category folders listed below. Unzip it to browse.
– README.md: this file. It lists every category with some example recipes, and it is updated every time a category or recipe is added.
– REPO_INFO.md: the repo name and a short description.

How to use it
1. Unzip Cookbook.zip. You get a Cookbook folder with one folder per category.
2. Open any recipe (.md). Each has a title, servings, ingredients, and numbered instructions.
3. To read recipes directly on GitHub, also upload the unzipped Cookbook folder to the repo.

Ground rules
– Every category has at least 20 recipes.
– No repeated recipes. A few cooking-method pairs are kept on purpose (for example, slow-cooker and Instant Pot carnitas).
– Every folder is alcohol-free except 50_With_Alcohol, where each recipe is clearly flagged and has its own Alcohol Used section.
– Left out by request: vegetarian, vegan, and ramen categories, and cocktails. Folder numbers 07, 37, and 39 are intentionally unused.
